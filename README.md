# FPGA VGA Graphics System

This project implements a VGA graphics generator using Verilog on an FPGA board.

The system generates video signals to display custom graphics on a 640×480 VGA monitor using pixel-based rendering.

---

## 🧠 Overview

The project uses digital logic to control VGA timing signals and display graphical content by assigning colors to specific pixel coordinates.

---

## ⚙️ Features

- VGA signal generation (640×480 resolution)
- Horizontal and vertical synchronization
- Pixel-based rendering logic
- Custom graphics displayed on screen (including pixel art)

---

## 🏗 System Architecture

FPGA → VGA Signal Generation → Monitor Display

---

## 🧰 Technologies Used

- Verilog
- FPGA Development Board
- VGA Interface
